Privacy Policy

Effective Date: March 2026 | Last Updated: March 2026

Xolby ("we", "our", or "us") is committed to protecting your privacy. This Privacy Policy explains how Xolby collects, uses, stores, and protects information when you use our Discord bot and web application services, including our TikTok integration features.

1. Information We Collect

Xolby only collects the minimum data required to deliver core bot and integration functionality:

  • Discord User Identifier & Guild Data: We store Discord user IDs, guild (server) IDs, and channel IDs to manage user settings, moderation logs/warnings, reminders, and persistent live tracker embeds.
  • TikTok Authorization Data: When you connect your TikTok account via official Web OAuth, we store your TikTok Open ID, display name, and OAuth tokens.
  • TikTok Video Metrics Snapshots: For connected users, we periodically snapshot public video metrics (view count, like count, comment count, share count, favorite count, video title, and video ID) retrieved from official TikTok API endpoints to power historical charts and live stats.

2. How We Use Information

We use collected data strictly for the following operational purposes:

  • Retrieving and displaying your recent public TikTok video analytics and calculated engagement rates in response to Discord commands (e.g., /tiktokstats, /tiktoklive, /tiktokhistory).
  • Maintaining active live tracker embeds across authorized Discord server channels.
  • Managing Discord moderation actions, warnings, and channel state settings.

3. Token Security & Storage

Security of user credentials is our top priority:

  • OAuth Secrets: TikTok Client Secrets, access tokens, and refresh tokens remain strictly server-side.
  • Encryption at Rest: Access tokens and refresh tokens are encrypted at rest in SQLite using Fernet symmetric encryption. Tokens are NEVER stored in plaintext.
  • No Password Access: Authorization occurs on official TikTok authorization servers (https://www.tiktok.com/v2/auth/authorize/). Xolby never requests, receives, or stores your TikTok password.
  • No Token Exposure: Access tokens, refresh tokens, and client secrets are NEVER printed in logs, HTML output, Discord messages, or public API responses.

4. Data Sharing & Third-Party Services

Xolby does NOT sell, rent, or trade user data to third parties or advertising networks. We interact with official third-party APIs solely to provide features:

  • TikTok Display API v2: Official TikTok API used to fetch user basic info and public video statistics.
  • Discord API: Official Discord API used to process slash commands and update messages.
  • Google Gemini API: Optional AI API used strictly for read-only code scans when executing /scan.

5. Data Retention & Disconnection / Deletion

You have full control over your data:

  • TikTok Disconnection: Running /tiktokdisconnect in Discord immediately revokes stored OAuth access tokens via TikTok's official revoke endpoint and permanently deletes your TikTok account record and active live trackers from our database.
  • Server Removal: Server moderation logs and warnings remain tied to server IDs until purged or reset.

6. Children's Privacy

Xolby is not directed to children under 13 years of age (or applicable Legal Age in your jurisdiction). We do not knowingly collect personal data from children.

7. Policy Changes

We may update this Privacy Policy from time to time to reflect service improvements or legal updates. Updated policies will be published directly on this page with a revised effective date.
