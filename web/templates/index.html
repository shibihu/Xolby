TikTok Developer & API Compliance

Xolby strictly uses official TikTok Display API v2 endpoints (user.info.basic, video.list) to access authorized public user metrics.

  • No Password Access: OAuth account authorization takes place directly on TikTok's secure domain. Xolby never asks for or stores user passwords.
  • Server-side Token Encryption: Access and refresh tokens are encrypted at rest on the server and never exposed in logs, API responses, or Discord messages.
  • TikTok Studio Metrics Notice: Internal creator studio analytics such as average watch time, audience retention percentage, and full play duration are TikTok Studio-only metrics and are strictly noted as unavailable in standard Display API v2.
